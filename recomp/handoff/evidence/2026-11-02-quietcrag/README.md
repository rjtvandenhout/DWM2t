# QuietCrag: original appraisal and generated-world Journal

An independent copy of the genuine A Class champion Journal, SHA-256 `5afe17c1e9817cf9229af195690ba0834fccbe8155bf9992e6415f6a45d4ee00`, was continued in the R4 full-ROM diagnostic Windows executable, SHA-256 `61a0e6d3ff84b5322b101247fc93ff6889f123a1bcd94df663135757fb3b9855`, under Wine on 2 November 2026. Original P1 inputs were used throughout; RAM was read only, with no save, money, key or RNG injection. Squiz was not used or bred.

At the original Key Shop, the existing unappraised key record `FE 07 21 1B`, seed `0xB7C5`, cost [280G to appraise](appraisal-280g.bmp). The shop identified it as [QuietCrag](quietcrag-appraised.bmp), leaving 2076G of the original 2356G. The original portal generated its world; PLAN > Journal displayed [the original save confirmation](journal-confirmed.bmp). The resulting genuine 32768-byte Journal, SHA-256 `9a6a450a7057c8ca05f03298fd93b1605bdb02396ad80b4d12803fa1e5e1966b`, was preserved outside the repository at `/workspace/scratch/arena-s-keys-2026-11-02/quietcrag-original-journal.sav`.

A separate fresh diagnostic process [continued the Journal](fresh-continue.bmp), returning a byte-for-byte identical 32768-byte SRAM and the same observed generated-world reward array `00 60 00 00 80 00 00 00 00 00 00 02 00 00 00 00`. The read-only [structure observation](reward-observation.txt) identifies a three-floor type-4 dungeon in region [3,1] with reward byte `$60`, and a five-floor type-4 dungeon in region [5,6] with reward byte `$80`. The original item records identify `$60` as `Thief<55>`, with a source-calculated 1500G main-merchant sale price; original reward code identifies `$80` as a Magic Key. These are leads, not claims that either chest was opened, the item sold, or another key obtained. No `$81` DreamEgg reward occurs in this particular observed array; acquisition and hatching were not tested here.

The [original P1 command list](original-p1-commands.txt) and [trace](original-p1-trace.txt) are retained. Screenshots and traces do not contain a ROM or save. Fresh Continue and source-derived prices under Wine do not establish every generated world, physical link, or native Windows behavior.
