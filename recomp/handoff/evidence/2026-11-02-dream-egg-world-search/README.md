# DreamEgg search: original FirstField and BlackIslet worlds

This is a bounded postgame search, not proof that DreamEgg acquisition, feeding or hatching works. No DreamEgg was found or acquired. Squiz was not used. All game progress below used original game P1 inputs and independent copies of genuine Journals; runtime memory snapshots were observed only.

An original strong-party Journal with the genuinely traded FirstField key (seed `0x1927`, SHA-256 `ecddb6f4a31b8b53d912140f77ee1347ac638091ecf75bed3d74b6f21b01b8af`) was used to traverse the FirstField dungeons. Original chests yielded a [Magic Key](firstfield-magic-key.bmp) (key record `FE08281B`, seed `0xC887`) and [SteelFang](firstfield-steelfang.bmp). A separate line sold SteelFang for 375G, then won the original [FirstField castle battle](firstfield-boss.bmp) and saved 386G. The original return portal took the player back to GreatLog, where [Journal recorded progress](greatlog-journal.bmp). That hub save SHA-256 is `61510b4446b038f4034f90bfc5656b1861eb0f4abc6ae65ba65a44564c9ece3e`.

On an independent line, the original Key Shop [charged 280G](blackislet-appraisal-price.bmp) and [identified the new key as BlackIslet](blackislet-appraised.bmp). Using it in the original key portal generated the world; [Journal saved it](blackislet-journal.bmp), and [a fresh Continue](blackislet-fresh-continue.bmp) restored it with all 32768 SRAM bytes identical. World Journal SHA-256: `b056331e5317a7cd0ecc312cea3b06327607478f372d5d53e55375689be3d3c6`. The player controlled Garon, Slash and Derzo throughout this line.

The generated world's read-only original-RAM reward array `CE8B..CE9A` was `00 40 00 80 42 00 00 00 00 00 00 00 00 00 20 00`, reproduced after Continue. Its two type-4 dungeons have five floors; see [original-map observation](blackislet-observation.json). Original game code uses reward byte `81` for the special DreamEgg branch; none occurs in this concrete world. This observation is not a test of acquiring or hatching an egg, nor evidence about other seeds. The [controller trace](blackislet-controller-trace.txt) starts at the authentic FirstField-clear Journal and includes actual inputs, checks and save sequence.

The run used the diagnostic full-ROM Windows executable SHA-256 `61a0e6d3ff84b5322b101247fc93ff6889f123a1bcd94df663135757fb3b9855` under Wine on a private display. Earlier FirstField routes and exact save copies are retained under `/workspace/scratch/dreamegg-validation-2026-11-02/`; no cartridge save files or ROM data are committed here.

The earlier FirstField lines' finite original inputs are retained as [Magic Key](firstfield-key-p1.txt), [SteelFang](firstfield-steelfang-p1.txt), and [sale and boss](firstfield-boss-p1.txt). The last `journal` command in the boss trace omitted its required diagnostic checkpoint name and stopped that diagnostic session; it did not save. The FirstField boss Journal had already been made through the in-game menu, and the subsequent documented GreatLog/BlackIslet run began from that intact saved Journal.

Both BlackIslet type-4 dungeons were subsequently traversed on the same original-input line, all five floors each. The first gave [VITbelt](blackislet-vitbelt.bmp), followed by a real [Journal](blackislet-vitbelt-journal.bmp) and byte-identical fresh Continue. The second gave [MagicBelt](blackislet-magicbelt.bmp); its subsequent original [Journal](blackislet-two-belts-journal.bmp), SHA-256 `08392bb4eefbdcf41953e0a59eb28856c8b573c2c02f6069105d7158adc0ffe6`, independently [continued](blackislet-two-belts-fresh-continue.bmp) with all 32768 SRAM bytes identical. Gold remained 106G. [Original P1 commands](blackislet-both-dungeons-p1.txt) include the traversals and Journal inputs. The source-observed `80` reward belongs to BlackIslet's type-6 structure index 3, not either type-4 dungeon; these two chests do not prove a fourth key or DreamEgg.

After a legitimate original Arena B win, an independent copy of the original champion Journal SHA-256 `7c5cd3cb1655c6d1d4439820a04c7ebed708a25ffd784161d0668e8a32d2dbed` contained a new unappraised Magic Key (record `FE03171B`, seed `0x23B7`). At the original portal, its attempted use displayed [“The key could not be used yet”](arena-b-key-unappraised.bmp). At the original Key Shop, the [quoted appraisal was 280G](arena-b-key-appraisal-280g.bmp), while the Journal had 1G. [P1 commands](arena-b-key-appraisal-p1.txt) record this bounded attempt. The new key was not appraised or used to generate a world, so no DreamEgg result is claimed for this seed.

The original Arena B prize was subsequently transferred by an authentic two-profile key trade to the independent 386G GreatLog hub Journal; the link agent separately verified fresh Continue, both complete original party records, quest bytes and key seed. On that traded line, the original Key Shop actually charged 280G and identified the B key as [BlueHill](bluehill-appraised.bmp). The original portal generated it and [Journal recorded it](bluehill-journal.bmp). A [fresh Continue](bluehill-fresh-continue.bmp) loaded identical 32768-byte SRAM; SHA-256 `91d52195a0a82e69bf5991c7e519aed888da4f50b7286ddb6f60b691ba6fc606`. Original game-input and assertion details: [trace](bluehill-trace.txt); decoded original RAM and map structures: [observation](bluehill-observation.json). This world has two type-4 dungeons, 3 and 5 floors, and reward array `00 50 00 00 49 00 00 00 00 00 00 00 00 08 00 00`: no special egg reward `$81` was observed. This is a negative observation for that world, not an egg acquisition or feeding test. The linked raw post-exchange SRAM changed on the first diagnostic Continue; the B key and party were observed after Continue, and the exact byte-identity claim applies only to the later BlueHill Journal.

On an independent copy of the authentic Arena A champion Journal (`5afe17c1e9817cf9229af195690ba0834fccbe8155bf9992e6415f6a45d4ee00`), the original Key Shop charged 280G and identified the A-prize key as [FirstMoon](firstmoon-appraised.bmp). The actual selected runtime record was `0004331b`, stored seed bytes `33 dc` (`0xDC33`). After using it through the original portal, [Journal](firstmoon-journal.bmp) saved the world, and a separate [fresh Continue](firstmoon-fresh-continue.bmp) restored all 32768 SRAM bytes identically. The FirstMoon Journal SHA-256 is `3ff373cc02524c818e6f7c99ef4dbc4b55d5d818996a33c4c9b8a13d3bbb5bdf`; the [P1 trace](firstmoon-trace.txt) and [read-only original-map observation](firstmoon-observation.json) are retained. Its four actual structures include one four-floor type-4 dungeon at surface region (4,6), with reward byte `$43`; the source item table identifies that as OddBelt with a 375G resale value, but the chest was not opened in this experiment. The observed 16-byte reward region contains no `$81`; `$49` and `$80` in positions beyond the four actual structures cannot be attributed to active dungeon rewards. This specific generated world provides no observed DreamEgg reward, and no egg pickup, feeding or hatching is claimed.

Its observed reward array contains no `$81` DreamEgg. These observations are limited to the documented seeds and do not establish egg feeding or hatching.
