# S Class funding and original-input attempts

The party was already the original A Class champion, with 2356G, in an independently copied Journal SHA-256 `5afe17c1e9817cf9229af195690ba0834fccbe8155bf9992e6415f6a45d4ee00`. The full-ROM R4 diagnostic executable SHA-256 `61a0e6d3ff84b5322b101247fc93ff6889f123a1bcd94df663135757fb3b9855`, source `1351bcd058e491455a477045a2ff86bbc3bd7b1c`, ran under Wine on Linux. Only original controller inputs were supplied; RAM and screenshots were read-only observations. No game memory, RNG, money, item or Journal bytes were injected. Squiz was not used or bred.

## Original BlueHill challenger and proceeds

In BlueHill the party met an original challenger at surface region (3,2), position (128,32), who [offered a reward for a win](bluehill-challenger-offer.bmp). After the original battle was won, [the reward dialogue](bluehill-challenger-won.bmp) awarded consecutive items in the same uninterrupted interaction. The actual inventory gained two Sirloins, one Rib, one BeefJerky and twelve PorkChops; see the [first Sirloin](bluehill-first-sirloin.bmp), [second Sirloin](bluehill-second-sirloin.bmp) and [last reward dialogue](bluehill-inventory-full-dialogue.bmp). The dialogue ended when all 24 inventory slots were full; no repeated reinteraction or general farming rate is asserted. The original save confirmation is [shown here](bluehill-fullbag-journal.bmp).

An [independent PyBoy run of the original Cobi ROM](../2026-11-02-bluehill-original-pyboy/README.md) from the same genuine pre-event Journal reproduced one challenger victory followed by 16 meat rewards in one dialogue ending at a full inventory. Individual meat types differed under RNG. This supports the observed original-game behavior for the tested case; it is not a claim that all RNG outcomes or all mechanics were compared. The original full-bag Journal SHA-256 `ac071bbc4d66aa16d3baf7e4a0ccfbbe80b2f3b70661c9303786fa2885fa8cc0` was [continued in a fresh process](bluehill-fullbag-continue.bmp), with all 32768 SRAM bytes identical.

On an independent copy of that Journal the player sold the actual acquired meat and other sellable items to the original GreatLog merchant. The game displayed [4468G](first-sale-4468g.bmp); only Change remained. A normal Journal and fresh Continue produced the same 32-KiB save SHA-256 `31833e82cfd7ecaf67b1ba8b306ba7bdc18317659f9c54b1c11b246ba8eee70c`.

## QuietCrag and S entry

On that same playthrough the player paid the original [280G appraisal](quietcrag-appraisal-280g.bmp), and the game identified the existing B-prize key as [QuietCrag](quietcrag-appraised.bmp). The 4188G original Journal SHA-256 `3e276cc592141146bfc398f5be80203c206749749588ca200417302fb85d6085` passed fresh Continue with byte-identical SRAM. The original key generated QuietCrag, and a three-floor dungeon chest gave [Thief](quietcrag-thief-obtained.bmp), runtime item ID 96. The original [Journal confirmation](quietcrag-thief-journal.bmp) produced SRAM SHA-256 `cbc4e55469bf707fceec878d043f1a055f26936f7d268ca141161142a0f6351d`; a [fresh Continue](quietcrag-thief-continue.bmp) restored ID 96 and byte-identical SRAM. The earlier exploratory source lookup called this item Cleric; the original screen and corrected original item table identify ID 96 as Thief.

The party returned by the original portal and sold that actual item for the original [1500G offer](quietcrag-thief-sale-1500g.bmp); the merchant displayed [5688G](funds-5688g.bmp). The original pre-S Journal SHA-256 `c92a1df20e3dd14988d35ea3192175d6c121070b741ec956d0a9aed7864a0bfd` passed [fresh Continue](pre-s-continue-evidence.txt), with the whole 32768-byte SRAM identical. This Journal remains the preserved starting point for the attempts below. It contains the A championship and 5688G; no saves or binaries are included here.

## Three actual S attempts

The original receptionist offered [S Class for 5000G](s-entry-5688g.bmp), and the player paid using the actual in-game balance. Three original-input attempts were made on separate continuations; the second and the training continuation began from the actual pre-S Journal in fresh processes.

1. Garon used Defense; Slash and Derzo used Charge. The game confirmed [victory in battle one](s-first-attempt-round1-win.bmp). [Battle two began](s-first-attempt-round2-hp.bmp) with only Derzo alive at 137 HP. A further Defense choice did not revive the team, and the original receptionist showed [defeat](s-first-attempt-loss.bmp).
2. Garon and Slash used Defense, Derzo Charge. The game confirmed [victory in battle one](s-second-attempt-round1-win.bmp). [Battle two began](s-second-attempt-round2-hp.bmp) with Slash at 181 HP, Derzo at 107 HP and Garon unconscious. Original Slash Charge/Derzo Defense inputs were attempted, followed by [defeat](s-second-attempt-loss.bmp).
3. On a separate continuation of the genuine 5688G Journal, two original QuietCrag overworld victories raised Garon from level 40 / 327683 EXP to level 41 / 328447 EXP. Read-only original monster records showed maximum HP 220→222, maximum MP 284→292, ATK 358→366, DEF 231→233, AGL 295→303 and INT 209→211. The game itself [displayed level 41 and the restored party with 5688G](trained-garon-level41.bmp). An original Journal SHA-256 `a261d433e47f1ad62fbcdf43e6095d49afd170ad0ebe2aedf22f4964b572f797` passed [fresh Continue](trained-garon-fresh-continue.bmp), preserving all 32768 SRAM bytes exactly; its [field comparison](trained-garon-continue-evidence.txt) reported no mismatch. This was a bounded two-battle training test, with no breeding. Garon Defense / Slash Charge / Derzo Charge then [won S battle one](s-trained-round1-win.bmp). [Battle two began](s-trained-round2-start.bmp) with only Derzo alive at 79 HP. Derzo's original Defense tactic [revived Garon](s-trained-garon-revived.bmp) but Derzo fell, leaving [Garon alone at 111 HP](s-trained-garon-alone.bmp); the battle ended in [defeat](s-trained-round2-loss.bmp).

The strongest result among these three attempts was **one battle won followed by a battle-two loss**. A later bounded [ten-variant follow-up](../2026-11-02-arena-s-batch/README.md) reached the third battle in two independently executed variants, both of which lost it. No S championship or reward is claimed. The three losses above and the preserved pre-S Journal are distinct from the earlier, actually won [A Class](../2026-11-02-bluehill-arena-a/README.md).
