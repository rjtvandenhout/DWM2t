## Original title regression

The executable starts at the real CGB post-boot cartridge entry point `$0100`.
No external ROM file is loaded and no host-side title image is injected.

Accepted result:

```text
M5_TITLE_REACHED
frame=1921
hash=0x49c67a53ef4f8a80
stable_frames=30
C5DB=5
C5DC=0
```

The title framebuffer is the original **Dragon Warrior Monsters 2:
Cobi's Journey** title generated by original game execution.

AOT ROMX banks required by the boot/title path at this milestone:

```text
1, 2, 7, 127
```

The game also executes its copied HRAM OAM-DMA helper at `$FF80-$FF89`;
that fixed code fragment has an explicit native translation.
